# Wishlist

Things you'd like done when there's usage to spare. Jot them down during the week; the next
run takes them first. One line is enough, but "done when" helps a lot. The run ticks an item
once its branch is in your inbox; delete lines whenever you like.

Examples:

- [ ] webapp: CSV export breaks on commas in names. Done when an export with `Smith, J.` opens
      correctly in a spreadsheet.
- [ ] api: add tests for the rate limiter; it has none.
- [ ] cli: `--json` output for the `list` command.
- [ ] any repo: find out why CI got slower last month and tell me (no change needed).
