# Launch notes: draft only

No announcement or directory submission is authorised by preparing this package.

The plugin turns spare subscription allowance into small repository improvements on
reviewable branches. It uses a local Markdown inbox, isolated worktrees, staged leak
checks and verified branch backups. New installs keep branches local unless the user
explicitly opts into pushing.

## Things not to claim

- A hook is a security sandbox or prevents interpreter indirection.
- Usage samples guarantee zero paid overage.
- Unit tests establish clean-install or independent-user success.
- Codex or claude.ai runtime support.
- Hours saved, or a public release before the owner approves it.
